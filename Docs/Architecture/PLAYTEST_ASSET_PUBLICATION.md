# Original playtest and office asset publication

Reviewed 2026-10-31 for the public Foundryline repository. This exception adds only the explicit original files below. Existing exclusions for purchased packs, derived trucks/characters, maps with vendor dependencies, audio, builds, caches and player saves remain in force.

The office stair meshes are generated by the game component from saved layout records. Their four materials use only engine expressions and authored constant/procedural colours. Straight/turning catalogue renders are generated from original geometry in isolated Blender. No purchased textures or geometry are used.

Personnel-door leaves/frames and light-kit cartons are original procedural Blender geometry, with authored constant-colour materials. The office workstation/terminal source comes from `build_operations_assets.py`; the runtime chair remains an external licensed Factory asset and is not embedded in the published workstation. Its desk/computer materials are game-owned engine material graphs. The reviewed machine thumbnails show the already published original plasma/brake/roller meshes; the forklift-area thumbnail depicts an original painted floor area, not a purchased forklift mesh.

A coarse native-package vendor-path scan was also performed before staging; it supplements the generator/provenance review and is not a general asset-license certification. These original additions do not turn the source-only public clone into a complete playable asset distribution. Restore licensed local dependencies as described in `Docs/REPOSITORY_CONTENT.md`.
