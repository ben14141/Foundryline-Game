# Game-ready original models

This set contains original standalone editable Blender and FBX models: HeadacheRack, StandardWeldingBench, CurvedSheetCradle and WeldingFixtureKit. The bench grounding cable is stowed within its 8 ft x 4 ft footprint. The bench, rack, fixtures and rolled-sheet cradle are separate assets. No review-only tank, pallet or loaded product is embedded in their complete FBXs.

All materials/geometry are procedural and have no linked vendor libraries or external images. Blender export units are metres with scale1, Unreal converts to centimetres. The manifest contains native package paths, actual bounds, material parameters and source provenance. Origins are floor-centred except the headache rack's bed-rail datum, whose stake inserts extend below zero.

Native content and twenty original materials are published at their real game package paths. See Docs/Architecture/ORIGINAL_MODEL_ASSETS.md for use, dimensions, original previews, and gameplay-integration boundaries. The preparation tool uses local ArtPolish review copies as inputs; these final editable files are self-contained and do not need that staging tree to open.
